> I set my alarm for 6 a.m. to seize the day — the day filed a restraining order, so we settled out of court at noon.

## Run it

```sh
python3 main.py
```

`main.py` is standard-library only: it reads `line.txt` and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`). The line is 115 characters, inside the 1–200 gate.

## Why this line

Everyday subject (the morning alarm), a twist that pays off on the last word ("at noon"), and nothing spare: seize-the-day ambition vs. a day that sues for peace. Light, playful, lands on first read.
